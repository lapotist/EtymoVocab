# en-frequency.txt

`en-frequency.txt` lists the 50,000 most frequent English words, one per line, most frequent first, so
the line number is the rank. EtymoVocab uses it only to order word-family lists, putting common words
first; it never adds words, meanings or relations. Words not in the list are ordered after the listed
ones.

It is generated by `tools/frequency/build_en_frequency.py` from
[wordfreq](https://github.com/rspeer/wordfreq) 3.1.1 by Robyn Speer, keeping lowercase words only.
wordfreq's data has not been updated since 2024, so it reflects language use up to then.
